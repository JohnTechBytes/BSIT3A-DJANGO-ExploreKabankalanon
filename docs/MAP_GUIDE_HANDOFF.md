# Straight-line map guide

- In Explore Places, open Map, choose **Use my location**, and select a mapped place (or select a carousel card first). In Nearby, choose a card and use **Use my location** in the map or starting-point section. **Fit results** restores the other matching destination pins.
- The blue starting-point marker is separate from the single selected destination pin. The dashed line connects their coordinates directly; it is **not a road route, travel time, or turn-by-turn navigation**. External Directions links remain available for route planning.
- Geolocation requires user permission and a secure context (HTTPS or localhost). It is a one-time position, not continuous tracking; use **Update my location** to request it again. A chosen landmark is labeled as a landmark, not GPS. Coordinates are processed in the browser tab; the existing MapTiler service receives map tile requests for the area being viewed.
- Nearby's map remains beside results on larger screens and opens as a dismissible bottom panel on smaller screens without automatically moving the page. The map uses only recorded coordinates; these may need confirmation. Distance filters can remove a selection if it no longer matches.
- The installer `tools/map_guide_update/apply_map_guide.py` supports both the exact pre-palette public-experience baseline and the exact prior palette baseline. It checks all target files and relevant prerequisites, stops on unknown edits, verifies downloads before writing, and backs up changed code files. It does not modify the database or project media.
- Run unit tests with `node tools/tests/test_map_guide.cjs`; Django tests include `mysite.tests_map_guide_updater` and `mysite.tests_public_system`. Tests used isolated sample listings and mocked browser GPS; they do not prove a live device fix or availability of the MapTiler service.
