# Driving road route and Nearby map view

- In Explore Places, open Map, choose **Use my location**, and select a mapped place (or select a carousel card first). In Nearby, select a card to switch from results to the map section; **Back to results** restores the cards. Use **Use my location** in either the map or Nearby's starting-point section. **Fit results** clears the selected destination and restores the matching pins.
- With a starting point and destination, the browser requests a **driving route** from the OSRM public demo (`router.project-osrm.org`) and draws its returned road geometry. A separate marker shows the starting point. Routes use OpenStreetMap data, which may be incomplete, outdated or inaccessible; check conditions before travelling. The road line is not turn-by-turn navigation or a traffic-aware travel time. A warning appears when an endpoint is more than 200 m from the road OSRM used.
- The demo service is intended for reasonable non-commercial usage, permits at most one request per second, and has no uptime, freshness or latency guarantee. The client coalesces fast selections, spaces requests, cancels stale ones and shows an explicit failure with **Retry driving route**. It never substitutes a straight line and calls it a road. For production use, choose an appropriately supported routing service and comply with its terms.
- Geolocation requires permission and HTTPS or localhost. It is a one-time position, not continuous tracking; use **Update my location** to request it again. A chosen landmark remains a landmark, not GPS. When a starting point and destination are selected, their coordinates are sent to OSRM as disclosed on the page; the browser requests existing map tiles from MapTiler. No route request is sent to Django.
- Nearby list sorting and radius filters remain approximate **straight-line** distances, not driving distances. Locations are based on recorded coordinates and may need confirmation. A filter can remove a selection if it no longer matches.
- Run the independent client tests with `node tools/tests/test_map_guide.cjs`; Django tests include `mysite.tests_public_system` and the guarded updater tests. Browser checks used isolated sample listings, mocked GPS and mocked routing responses, not a live device or live OSRM/MapTiler service.
